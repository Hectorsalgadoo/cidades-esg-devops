# Projeto - Cidades ESG Inteligentes

Aplicação desenvolvida em .NET 8 (C#) para monitoramento de indicadores ESG no contexto de cidades inteligentes. O projeto possui pipeline automatizada de CI/CD via GitHub Actions, containerização com Docker e orquestração via Docker Compose.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem & Framework:** C# (.NET 8) / ASP.NET Core Minimal API
- **Containerização:** Docker & Docker Compose
- **CI/CD:** GitHub Actions
- **Documentação da API:** Swagger / OpenAPI

---

### Pré-requisitos
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) instalado e em execução.
- [Git](https://git-scm.com/) instalado.
